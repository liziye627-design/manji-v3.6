# 慢记 Manji v3.6

**一间由回忆慢慢布置起来的家。小狗是陪伴者，一件纪念物可以藏着两个人对同一天的不同记忆。**

本仓库是依据《慢记-编程AI执行计划书》（2026-10-07 版，见 `design/`）从零开发的移动端优先 Web 应用，含真实账户与会话、共同小家、可命名小狗、照片与文字回忆、手选纪念物、独立的双人视角、轻量承诺、纪念日、收纳查找、免费电子纪念作品、隐私与退出。**不包含任何旧 Heartbell 项目的点数、投入、冷静期、结婚门槛等已取消机制。**

## 快速开始

要求：Node.js ≥ 22.5（本机验证版本 v24.18.0）。**零第三方依赖，无需 npm install。**

```bash
# 方式一（推荐）：双击「打开交互首页.cmd」，或命令行运行独立启动器
#   端口 4332，独立 data/ 演示数据，自动播种演示账户并打开登录页
node scripts/start-home.mjs

# 方式二：直接启动（默认端口 4173）
node server/index.js

# 浏览器打开
#    http://127.0.0.1:4332/#/login （方式一）
#    http://127.0.0.1:4173        （方式二）

# 运行自动化验收（自起独立测试服务，不影响上面的数据）
node tests/run-acceptance.mjs        # 原业务 101 项
npm run test:navigation              # 空间寻路 21 项
npm run test:chain                   # 永恒之链 18 项（上链/校验/篡改检测/隐私）
npm run test:onchain                 # 公共链锚定离线验收 15 项（keccak/ABI 编码/承诺一致性）
node tests/onchain-e2e-mainnet.mjs   # 端到端实测（BOT 主网真实交易，消耗少量 BOT，需配置 .env.local）
```

可选配置：复制 `.env.example` 为 `.env` 修改端口、数据库与媒体目录、上传上限等。所有配置都有安全默认值，不含任何密钥。

前端图片素材已随仓库提供（`public/assets/img/`）。如需从 Blender 渲染原图重新生成（抠黑底 → 降采样 → 透明底 PNG），运行 `node scripts/build-ui-assets.mjs`（需同级目录存在 `ConsensusBell-Blender-V2鲜活与16动作/renders/`）。

## 双会话演示（计划书 9.3 演示脚本）

用两个不同的浏览器（或一个普通窗口 + 一个无痕窗口）：

1. 窗口一注册「A」，给小狗起名，在单人家**留下一小段**（海边照片或一句话），选**贝壳**放**窗台**。
2. 小家页点「邀请你回家」，生成邀请链接，复制发给自己（另一个窗口打开即可）。
3. 窗口二（无痕）打开链接 → 注册「B」自己的账户 → **接受邀请，回家**。此时 B 看不到 A 未共享的私密回忆与物件。
4. B 在自己的视角里留一段（示例：把 A 的那段回忆共享后进入补充，或自己新开一段），体验两个人各自署名的视角。
5. A 共享某段回忆后，B 点开家里的物件可以看到双视角；任一方「不再共享」立即对对方隐藏。
6. 承诺 Tab 建一条共同小约定（B 点「我也愿意」生效）；纪念 Tab 建一个未来纪念日（站内提醒）。
7. 纪念 Tab →「做一份纪念」：只用本人内容可直接生成并下载真实 PNG 明信片；勾选对方内容会发起版本授权，对方同意后才能生成。
8. 我的 Tab → 免费导出本人内容（ZIP：manifest.json + memories.md + 照片原文件）。
9. 我的 → 暂停与解除关联：单方确认立即解除，共同家冻结；双方回到各自的小家，本人内容仍可查看与导出，小狗陪伴延续。

## 数据与存储

- 数据库：`data/manji.db`（SQLite，WAL 模式）。删除即重置全部数据。
- 媒体：`data/media/`（原图、缩略图、作品 PNG、导出 ZIP 全部在此，无公开直链，一律经 `/api/media/:id` 或下载接口鉴权后读取）。
- 恢复：备份 `data/` 目录即可完整恢复记录、成员、授权与任务状态（M51 已验证重启持久化）。

## 安全与隐私要点

- 身份只来自服务端会话（httpOnly Cookie + 库内 SHA-256 摘要）；请求体里的 `userId/authorId` 一律无效（M46）。
- 私密内容对非作者返回不泄露存在性的 404，包括媒体 URL 直开（M06/M07/M47）。
- 撤回共享 / 内容更新 → 相关版本授权立即失效，引用它的作品与导出停止下载（M14/M33/M35）。
- 解除关联单方立即生效：冻结共同家、撤销交叉访问、取消待办与邀请（M39–M42）。
- 变更类请求要求 `X-Manji-Client: 1` 自定义头作为 CSRF 防线；服务端不启用 CORS。
- 写操作支持 `Idempotency-Key`，更新支持 `expectedRevision`（M48/M49）。
